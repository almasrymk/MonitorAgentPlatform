# 10 - Milestones

Work strictly in this order. Each milestone is a vertical slice: backend, portal, tests. "Accept" lists what
must be true before stopping for review. Task ids: **MC** = this repository, **LP** = Licensing Platform,
**AG** = agent repository.

After each milestone update `docs/PROGRESS.md` with: tasks done, test counts (unit / integration / gateway /
e2e), coverage, anything stubbed, open questions.
